# Data Schema Reference — Phase 1 Data Infrastructure

Generated by: Task 1.3 implementation  
Collector scripts: `scripts/first_hour_collector.py`, `scripts/options_data_collector.py`  
Last updated: 2026-06-25

---

## Directory Layout

```
data/
  first_hour/
    YYYY-MM-DD.parquet          — first-hour stock bars (one row per symbol per minute)
    YYYY-MM-DD_summary.parquet  — first-hour per-symbol summary (one row per symbol)
  stocks_1min/
    YYYY-MM-DD.parquet          — full-day stock 1-min bars (one row per symbol per minute)
  options_1min/
    YYYY-MM-DD.parquet          — options snapshots (one row per contract per minute)
    YYYY-MM-DD_skips.csv        — skip log (contracts excluded with reason)
  quality/
    YYYY-MM-DD_quality.md       — daily quality report
    QUALITY_WARNINGS.md         — cumulative warning log (appended on <85% completeness)
```

## 1. `data/first_hour/YYYY-MM-DD.parquet`

**Granularity:** one row per symbol per 1-minute bar  
**Collection window:** 9:28–10:35 AM ET  
**Source:** Alpaca StockDataStream websocket (1-min bars, SIP feed)

| Column | dtype | Raw / Derived | Description |
|--------|-------|--------------|-------------|
| `timestamp` | `datetime64[ns, UTC]` | Raw | Bar close timestamp (UTC, from Alpaca) |
| `symbol` | `string` | Raw | Ticker symbol (e.g. `AAPL`) |
| `open` | `float64` | Raw | Bar open price |
| `high` | `float64` | Raw | Bar high price |
| `low` | `float64` | Raw | Bar low price |
| `close` | `float64` | Raw | Bar close price |
| `volume` | `int64` | Raw | Bar volume (shares) |
| `vwap` | `float64` | Raw | VWAP from Alpaca bar data (`None` if not provided by feed) |
| `trade_count` | `float64` | Raw | Number of trades in bar (`None` if not provided by feed) |
| `pct_change_from_open` | `float64` | Derived | `(close − first_bar_open) / first_bar_open`; `None` if open=0 |
| `vol_ratio` | `float64` | Derived (**FALLBACK**) | **Currently equals raw `volume` (fallback).** Will be replaced with `current_volume / avg_30day_volume_same_time_of_day` once 2 weeks of history are available. Do not compare across days until the real ratio is implemented. |
| `range_pct` | `float64` | Derived | `(high − low) / first_bar_open`; measures intrabar volatility; `None` if open=0 |
| `gap_pct` | `float64` | Derived | `(first_bar_open − prior_close) / prior_close`; `None` if no prior-day data available |
| `above_vwap` | `bool` | Derived | `True` if `close > running_vwap` (cumulative since 9:28 ET); `None` if vwap unavailable |
| `opening_range_high` | `float64` | Derived | Highest `high` in 9:30–9:44 ET bars; locked at 9:45 ET; `None` before lock |
| `opening_range_low` | `float64` | Derived | Lowest `low` in 9:30–9:44 ET bars; locked at 9:45 ET; `None` before lock |

**Notes:**
- `vol_ratio` fallback: until 2 weeks of first-hour data exist, this column contains raw bar volume. Use `volume` column directly for comparisons. The transition to a real ratio happens when `scripts/first_hour_collector.py` is updated to load a 30-day same-time average.
- `gap_pct`: sourced from the most recent prior-day `_summary.parquet` close. `None` on the first collection day or if prior parquet is missing.

## 2. `data/first_hour/YYYY-MM-DD_summary.parquet`

**Granularity:** one row per symbol (end-of-first-hour aggregation)  
**Written:** after `first_hour_collector.py` finishes (after 10:35 AM ET)

| Column | dtype | Raw / Derived | Description |
|--------|-------|--------------|-------------|
| `date` | `string` | Metadata | `YYYY-MM-DD` date string |
| `symbol` | `string` | Raw | Ticker symbol |
| `open` | `float64` | Raw | First bar open (9:30 open price or first bar seen) |
| `high` | `float64` | Raw | Session high across all first-hour bars |
| `low` | `float64` | Raw | Session low across all first-hour bars |
| `close` | `float64` | Raw | Last bar close (most recent 1-min close ≤ 10:35) |
| `volume` | `int64` | Raw | Total first-hour volume |
| `bars_collected` | `int64` | Metadata | Number of 1-min bars collected (max 65) |
| `total_first_hour_return` | `float64` | Derived | `(close − open) / open`; `None` if open=0 |
| `first_hour_volume_ratio` | `float64` | Derived (**FALLBACK**) | Same fallback as `vol_ratio` above: currently equals total raw volume |
| `opened_above_prior_close` | `bool` | Derived | `True` if `open > prior_close`; `None` if prior close unavailable |
| `opening_range_high` | `float64` | Derived | Same value as locked `opening_range_high` in minute-bar parquet |
| `opening_range_low` | `float64` | Derived | Same value as locked `opening_range_low` in minute-bar parquet |
| `touched_opening_range_high` | `bool` | Derived | `True` if any bar's `high ≥ opening_range_high`; `None` if OR not available |
| `touched_opening_range_low` | `bool` | Derived | `True` if any bar's `low ≤ opening_range_low`; `None` if OR not available |

## 3. `data/stocks_1min/YYYY-MM-DD.parquet`

**Granularity:** one row per symbol per 1-minute bar  
**Collection window:** 9:28 AM – 4:05 PM ET  
**Source:** Alpaca StockDataStream websocket (SIP feed)

Schema is identical to the `first_hour` minute-bar parquet with the following differences:
- Collection window is full day (9:28 AM–4:05 PM), not first hour only
- `opening_range_high` / `opening_range_low` carry forward the 9:45 locked values for the entire day
- `gap_pct` is populated only on the first bar; subsequent bars carry the same value

| Column | dtype | Raw / Derived | Description |
|--------|-------|--------------|-------------|
| `timestamp` | `datetime64[ns, UTC]` | Raw | Bar close timestamp (UTC) |
| `symbol` | `string` | Raw | Ticker symbol |
| `open` | `float64` | Raw | Bar open |
| `high` | `float64` | Raw | Bar high |
| `low` | `float64` | Raw | Bar low |
| `close` | `float64` | Raw | Bar close |
| `volume` | `int64` | Raw | Bar volume |
| `vwap` | `float64` | Raw | Alpaca bar VWAP (may be `None`) |
| `trade_count` | `float64` | Raw | Trades in bar (may be `None`) |
| `pct_change_from_open` | `float64` | Derived | `(close − day_open) / day_open` |
| `range_pct` | `float64` | Derived | `(high − low) / day_open` |

## 4. `data/options_1min/YYYY-MM-DD.parquet`

**Granularity:** one row per option contract per 1-minute polling cycle  
**Collection window:** 9:28 AM – 4:05 PM ET  
**Source:** Alpaca `OptionHistoricalDataClient.get_option_chain()` REST API  
**Expiry buckets:**
- `"near"` — expiration within 7 calendar days of collection date
- `"swing"` — expiration 8–45 calendar days from collection date

**Skip rules** (contracts excluded before writing, see `_skips.csv`):
- `bid == 0` or bid < $0.01
- `spread > 40% of mid`
- `open_interest < 100` (now active — OI sourced from Trading API contracts endpoint)
- No underlying price available (no stock bar data yet for that symbol)

| Column | dtype | Raw / Derived | Description |
|--------|-------|--------------|-------------|
| `timestamp` | `datetime64[ns, UTC]` | Metadata | Time of REST poll (UTC) |
| `symbol` | `string` | Raw | Option contract symbol (OCC format, e.g. `AAPL260117C00200000`) |
| `underlying` | `string` | Raw | Underlying stock ticker |
| `expiration` | `string` | Derived | Parsed expiry `YYYY-MM-DD` from contract symbol |
| `strike` | `float64` | Derived | Strike price (dollars), parsed from contract symbol |
| `right` | `string` | Derived | `"C"` (call) or `"P"` (put), parsed from contract symbol |
| `expiry_bucket` | `string` | Metadata | `"near"` (≤7d) or `"swing"` (8–45d) |
| `bid` | `float64` | Raw | Latest bid price (`latest_quote.bid_price`) |
| `ask` | `float64` | Raw | Latest ask price (`latest_quote.ask_price`) |
| `mid` | `float64` | Derived | `(bid + ask) / 2` |
| `bid_size` | `float64` | Raw | Latest bid size (contracts) |
| `ask_size` | `float64` | Raw | Latest ask size (contracts) |
| `spread_pct` | `float64` | Derived | `(ask − bid) / mid` |
| `volume` | `float64` | Raw | Trade size from `latest_trade.size` (may be `None`) |
| `open_interest` | `Int64` | Raw | From Trading API `get_option_contracts` (`OptionContract.open_interest`). Reflects 1-2 day OCC lag. `None` if contract not returned. |
| `open_interest_date` | `string` | Raw | OCC as-of date for `open_interest` (`OptionContract.open_interest_date`). Always check this when using OI. |
| `implied_volatility` | `float64` | Raw | `OptionsSnapshot.implied_volatility` (annualised, decimal form) |
| `delta` | `float64` | Raw | `OptionsGreeks.delta` |
| `gamma` | `float64` | Raw | `OptionsGreeks.gamma` |
| `theta` | `float64` | Raw | `OptionsGreeks.theta` (per day, negative for long options) |
| `vega` | `float64` | Raw | `OptionsGreeks.vega` |
| `rho` | `float64` | Raw | `OptionsGreeks.rho` |
| `underlying_price` | `float64` | Raw | Underlying price at time of poll (from stock bar accumulator) |

**open_interest — RESOLVED (2026-06-25):** The `OptionsSnapshot` market-data
model does not expose OI. OI is now sourced from the **Trading API** contracts
endpoint via `TradingClient.get_option_contracts(GetOptionContractsRequest(...))`
(`OptionContract.open_interest` + `open_interest_date`), implemented in
`scripts/options_oi.py` and wired into the collector and probe. OCC computes OI
end-of-day and distributes it the next business morning, so values lag ~1-2
trading days — always read `open_interest_date`. Still to confirm on the first
live run (Gate 1A): the contracts endpoint returns data on the Basic plan and
the symbols join cleanly to chain snapshots.

## 5. `data/options_1min/YYYY-MM-DD_skips.csv`

Plain CSV log of contracts excluded from the parquet. Never silently dropped.

| Column | Description |
|--------|-------------|
| `timestamp` | ISO timestamp of skip decision |
| `symbol` | Underlying ticker (or contract symbol if available) |
| `contract` | Contract symbol or bucket name if symbol-level skip |
| `reason` | Skip reason: `bid_zero`, `spread_NN%`, `low_oi_NN`, `no_quote`, `no_price`, `api_error:…`, `rate_limit_deprioritised` |

## 6. Timezone Convention

All `timestamp` columns are stored in **UTC** as `datetime64[ns, UTC]` (tz-aware).  
Convert to ET for display: `ts.astimezone(ZoneInfo("America/New_York"))`.

All collection windows in code use `zoneinfo.ZoneInfo("America/New_York")` for correct DST handling.
