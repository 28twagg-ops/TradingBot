================================================================================

UNIVERSE (as coded):

  Meaning: S&P 500 + S&P MidCap 400 combined (~900 tickers after dedup).
  Tickers fetched from Wikipedia lists:
    - List_of_S%26P_500_companies
    - List_of_S%26P_400_companies

  Daily cache: logs/cache/tickers_YYYY-MM-DD.json

PRICE / HISTORY FILTERS (as coded):
  MIN_STOCK_PRICE  = 5.0        (skip if latest close < $5)
  MIN_HISTORY_DAYS = 220        (need at least 220 daily bars)

DATA SOURCE / TIMEFRAME:
  Daily OHLCV bars only (no intraday bars for signal generation).
  Primary: Alpaca StockHistoricalDataClient, TimeFrame.Day (~300 calendar days lookback).
  Fallback: yfinance daily download if Alpaca returns insufficient data.
  Indicators computed on daily Close/Volume/Open from these bars.

MARKET REGIME (SPY-based, as coded):
  regime(spy_df):
    bull        if SPY close / SPY 200-day MA >= 1.0
    correction  if ratio >= 0.93 and < 1.0
    bear        if ratio < 0.93
  (If SPY data unavailable or < 210 bars, defaults to "bull".)

REGIME PARAMETERS FOR RubberBand strategy only:
  BULL_P  = {consec_down: 5, rsi_thresh: 25, bb_std: 2.5, vol_z_min: 1.5, require_ma200: True}
  CORR_P  = {consec_down: 3, rsi_thresh: 30, bb_std: 2.0, vol_z_min: 0.5, require_ma200: False}
  BEAR_P  = {consec_down: 5, rsi_thresh: 20, bb_std: 2.5, vol_z_min: 1.0, require_ma200: False}
  prm = BULL_P if bull else CORR_P if correction else BEAR_P

INDICATORS COMPUTED (daily, on each stock):
  RSI(14)
  BBL25 = 20-day MA - 2.5 × 20-day std
  BBL20 = 20-day MA - 2.0 × 20-day std
  BBM   = 20-day MA (used as "midline" exit)
  VZ    = volume z-score vs 20-day volume mean/std
  MA50, MA200
  L252  = 252-day rolling minimum close (52-week low proxy)
  R60   = 60-day percent change
  GapPct = (Open - prior Close) / prior Close
  Green  = 1 if Close > Open else 0

SECTION 2 — ENTRY RULES (EXACT, AS CODED)
================================================================================

ACTIVE STRATEGIES (7 — all checked every trading day for every ticker):

  1. RubberBand (_rb)
     ALL of:
       (consecutive down days >= prm["consec_down"]) OR (RSI < prm["rsi_thresh"])
       Close <= lower Bollinger band (BBL25 if bb_std >= 2.4 else BBL20)
       Volume z-score >= prm["vol_z_min"]
       If prm["require_ma200"]: Close > MA200

  2. RSIRecovery (_rsi)
     ALL of:
       Prior day RSI < 30
       Today RSI >= 30  (cross back above 30)
       Volume z-score >= 0.3
       Green candle (Close > Open)

  3. 52wkLow (_52)
     ALL of:
       Close <= 52-week low (L252) × 1.05
       Volume z-score >= 0.5
       RSI > 10

  4. MomReversal (_mr)
     ALL of:
       60-day return (R60) < -0.12  (-12%)
       5-day return > -0.02  (not still falling hard)
       RSI < 40
       Volume z-score >= 0.3

  5. GapDown (_gd)
     ALL of:
       GapPct <= -0.03  (open gaps down >= 3% vs prior close)
       Green candle (Close > Open)

  6. VolumeSpike (_vs)
     ALL of:
       Volume z-score >= 2.5
       5-day return >= -0.01 and <= 0.05

  7. Pullback50 (_pb)
     ALL of:
       Close > MA200  (uptrend)
       abs(Close - MA50) / MA50 <= 0.01  (within 1% of 50-day MA)
       Green candle (Close > Open)

DORMANT / REMOVED STRATEGIES:
  GoldenCross — removed from codebase (not in get_signals() loop).

SIGNAL SELECTION PER TICKER:
  get_signals() runs all 7 strategies; may return multiple signals per ticker.
  Monthly schedule defines "seasonal" pair (primary + secondary); see Section 5.
  Signals tagged seasonal=True if strategy name matches that month's primary or secondary.
  Sort order: seasonal signals first, then alphabetical by strategy name.

POSITION SIZING (as coded):
  SEASONAL_SIZE_PCT    = 0.20   (20% of equity — scheduled primary/secondary strategies)
  OFFSCHEDULE_SIZE_PCT = 0.20   (20% of equity — other firing strategies)
  CASH_RESERVE_PCT     = 0.05   (5% of equity kept as reserve; not deployed)
  MIN_TRADE_SIZE       = 0.01   (minimum dollars per entry slot math)

  Signal-scaled sizing when many signals:
    avail = cash - (equity × CASH_RESERVE_PCT)
    n_slots = min(viable_signals, max_trades)
    equal_share = avail / n_slots
    sea_da = max(MIN_TRADE_SIZE, min(equity × SEASONAL_SIZE_PCT, equal_share))
    off_da = max(MIN_TRADE_SIZE, min(equity × OFFSCHEDULE_SIZE_PCT,
                 equal_share × (OFFSCHEDULE_SIZE_PCT / SEASONAL_SIZE_PCT)))

CONCURRENT POSITION CAP (as coded):
  MAX_OPEN_POSITIONS = 5
  max_trades = max(1, int(avail // MIN_TRADE_SIZE))
  max_trades = min(max_trades, max(0, MAX_OPEN_POSITIONS - len(open_positions)))

SECTION 3 — EXIT RULES (EXACT, AS CODED)
================================================================================

EXIT_STOP_LOSS = -0.005   (-0.5% from entry, as fraction of P&L)
EXIT_DAYS_MAX  = 3        (max calendar days held)

check_exit(df, pos, eod_only) priority:
  1. Stop loss: if position pnl_pct/100 <= EXIT_STOP_LOSS → exit "stop_loss"
  2. Max hold: if calendar days since entry_date >= EXIT_DAYS_MAX → exit "max_hold"
  3. Midline: if eod_only=True AND Close > BBM (20-day MA) → exit "midline"
     Midline is NOT checked on intraday exit runs (eod_only=False).

EXIT TIMING:
  Intraday exit runs (9:30am–3:29pm ET, every ~15 min): stop-loss + max-hold only
  Evening scan (3:44–3:59pm ET): all exits including midline (eod_only=True)
  Extended hours (4:00–8:00pm ET): stop-loss + max-hold only (no midline)

BROKER STOP ORDERS (parallel to software exits):
  GTC stop-MARKET sell on whole shares only (qty = floor(position_qty))
  Trigger price = entry_price × (1 + EXIT_STOP_LOSS)  [e.g. entry × 0.995]
  Skipped if position is fractional (< 1 whole share)
  place_all_stops() at start of morning exits and after buy loop
  place_eod_stops() at end of scan: cancels old stop, places new stop at
    current_price × (1 + EXIT_STOP_LOSS)

SOFTWARE SELL BEHAVIOR (do_sell):
  Cancels any open SELL orders for ticker before software exit
  urgency="urgent" (stop breach, regular hours): market sell immediately
  urgency="normal": limit sell 0.2% below current (0.998×), poll, then market fallback
  extended_hours=True: DAY limit at 0.9985× current; no market fallback

SECTION 4 — EXECUTION / BROKER MECHANICS (FACTS)
================================================================================

BROKER: Alpaca (TradingClient + StockHistoricalDataClient)
ACCOUNT: Live (PAPER_TRADING = False). Code comments reference ~$500 account size.
         MAX_OPEN_POSITIONS=5 sized for ~$90/slot at that equity level.

FRACTIONAL vs WHOLE SHARES:
  Entries use notional market orders → typically fractional share quantities.
  GTC stop-MARKET orders require whole shares (floor(qty)); fractional positions
  skip broker stop and rely on software exits (morning/intraday/ext_exits).
  Fractional positions tracked in logs/fractional_watch.json when stop skipped.

ORDER TYPES USED:
  BUY:  MarketOrderRequest, notional dollars, DAY
  SELL (urgent stop): close_position / market
  SELL (normal): LimitOrderRequest then market fallback if unfilled
  SELL (extended hours): LimitOrderRequest DAY only
  STOP: StopOrderRequest GTC on whole shares at stop_price

EXIT CHECK FREQUENCY:
  ~Every 15 minutes during regular session (9:00am–2:30pm Chicago / 10:00am–3:30pm ET)
  Plus dedicated morning windows (8:30–8:45 Chicago) and evening scan + ext_exits

BROKER CONSTRAINTS (factual):
  Alpaca rejects GTC stop orders on fractional quantities.
  Extended hours: limit orders only (no market orders).
  DAY orders used for extended-hours limit sells (GTC not allowed on fractional).

USE_EXTENDED_HOURS_SELL = False  (extended-hours path exists but flag is False;
  ext_exits mode still uses limit sells when extended_hours=True in do_sell)

TWO-PHASE PLAN (USE_TWO_PHASE_PLAN = True):
  evening_prep builds signal plan → logs/plans/evening_plan.json
  scan executes plan (PLAN_MAX_AGE_MIN = 120 minutes)
